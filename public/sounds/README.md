# Key sound recordings

Every folder here is a switch recorded by [kbsim](https://github.com/tplai/kbsim) by Thomas Lai
(`src/assets/audio/`), used under the MIT licence — see `LICENSE-kbsim.md`. File names were lowercased.

| Folder | Switch |
|---|---|
| `cream` | NovelKeys Cream |
| `alpaca` | Alpaca |
| `redink` | Gateron Red Ink |
| `turquoise` | Turquoise Tealios |
| `mxblack` | Cherry MX Black |
| `holypanda` | Holy Panda |
| `mxbrown` | Cherry MX Brown |
| `mxblue` | Cherry MX Blue (no Space/Enter/Backspace recordings) |
| `bluealps` | SKCM Blue Alps |

Each switch has `press/` sounds per keyboard row (`generic_r0`–`generic_r4`, top row = r0)
plus `space`, `enter` and `backspace`, and `release/` sounds for generic keys, space,
enter and backspace. The app uses rows r1–r3.
